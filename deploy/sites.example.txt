# Образец списка сайтов, которые живут на ЭТОМ коде. Настоящий список —
# deploy/sites.txt, он ЛОКАЛЬНЫЙ и в git не идёт (.gitignore): репозиторий
# открытый, а сайты на этом коде — разные магазины, и их домены не должны
# стоять рядом ни в одном публичном файле. Скопируйте образец и впишите свои:
#
#   cp deploy/sites.example.txt deploy/sites.txt
#
# Одна строка — один сервер:
#
#   <ssh-алиас>   <домен>
#
# Алиас обязан быть настроен в ~/.ssh/config через Tor (как istore2-onion);
# домен уезжает в Caddyfile и в PUBLIC_ORIGIN — адрес возврата кассы, — поэтому
# ошибиться в нём значит вернуть покупателя после оплаты на чужое имя.
#
# По этому списку идёт `deploy/deploy-all.sh`: каждая правка кода выкатывается
# на ВСЕ сайты отсюда. Отличия сайтов (название, реквизиты, кассы, домен) живут
# в настройках каждого сервера, а не в коде — см. «Два сайта из одного
# репозитория» в CLAUDE.md.
#
# istore2-onion   первый-домен.example
# istore3-onion   второй-домен.example
