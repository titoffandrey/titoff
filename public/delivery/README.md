# Логотипы перевозчиков

Сюда кладутся логотипы способов доставки. Имя файла — **id способа** из
`lib/delivery.js`:

```
public/delivery/cdek.svg
public/delivery/ozon.svg
```

Файла нет — на витрине остаётся название текстом, раскладка не ломается.
После добавления файла нужен перезапуск процесса: логотипы читаются один раз
при старте (`pm2 restart istore` на сервере).

## Требования к файлу

- **Только SVG.** PNG на retina пришлось бы отдавать в 2× и 3×, и всё равно он
  мылится на промежуточных масштабах; SVG чёткий на любом экране и весит меньше.
- **Обязателен `viewBox`** — по нему логотип масштабируется через `<use>`, а
  высоту задаёт CSS (19 px). Без `viewBox` файл игнорируется, и остаётся текст.
- **Не больше 24 КБ.** Вордмарк весит 1–3 КБ; файл заметно тяжелее — это либо
  растр внутри SVG, либо логотип со всей презентацией бренда.
- Атрибуты `width`/`height` в корне не нужны, но и не мешают: размер задаёт CSS.
- Цвета оставляйте как в брендбуке — логотип не красится `currentColor`, в
  отличие от глифов характеристик в `public/spec-icons/`.

## Что делает загрузчик

`lib/delivery-logos.js` инлайнит файлы в страницу одним спрайтом, а перед этим:

- **чистит содержимое** — выкидывает `<script>`, `<foreignObject>`,
  обработчики `on*` и ссылки на внешние адреса. Файлы приходят снаружи, а инлайн
  чужого SVG в HTML исполняет всё, что внутри;
- **добавляет приставку к служебным id** (градиенты, обтравки). В брендбуках это
  сплошь `id="a"`, и без приставки второй логотип на странице красился бы
  градиентом первого.

Скачивать логотипы нужно с официальных страниц брендов — там же указаны правила
использования (минимальные размеры, охранное поле, запрет искажений).
