# Работа с этим магазином

С 20 сентября 2026 это самостоятельный проект одного магазина. Эти правила
заменяют прежние указания CLAUDE.md о едином коде и выкатке на несколько сайтов.

- Меняйте код, проверяйте и коммитьте только в текущем репозитории. Правки другого
  магазина не копируйте сюда без прямой просьбы пользователя.
- `deploy/sites.txt` локальный и содержит ровно один SSH-алиас и домен.
  Не публикуйте домены, адреса, секреты и локальные данные в репозитории.
- `deploy/project-id` — постоянный идентификатор этого проекта. Не копируйте его
  из соседнего репозитория и не меняйте ради обхода отказа выкатки.
- После необходимых проверок и коммита `./deploy/deploy-all.sh` выкатывает только
  этот проект. Прямой `install.sh` проверяет то же назначение и серверную привязку.
- Первый перенос на раздельную схему требует `deploy/bind-project.sh` с проверенным
  commit из серверного `deployed-from.txt`. Существующую чужую привязку не заменяйте.
- Сервер доступен только через локальный SSH-алиас с Tor. Витрину проверяйте
  изнутри сервера либо через Tor-SOCKS, без прямого запроса с ноутбука.
- Данные магазина лежат на сервере в `/var/lib/apple-store`, приложение —
  `/home/titoff/istore`. Работайте с данными от `titoff` и с `STORE_DATA_DIR`.
- Для локального просмотра используйте отдельный временный каталог данных.
  Не запускайте локально копию боевых настроек, касс, Telegram или почты.
- Демо-отзывы не создавайте и не публикуйте без прямой просьбы владельца.
  Автогенерация, ночное обновление и наполнение отзывами при запуске отключены.
  Ручная генерация создаёт новые записи только на модерации; публикует владелец.

Технические сведения и проверки находятся в CLAUDE.md; старые записи про общую
выкатку и настройки как единственный способ отличать магазины теперь исторические.
